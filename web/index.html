How tags work here

App data tag: holds the compressed page as a custom record (max capacity). Open this app → NFC → tap the tag.

Link tag: holds a URL with the page packed after the #. Any phone opens it from the lock screen; the page is decoded on the phone and never sent to a server.

Writing & in-app reading use Web NFC → Chrome on Android. iPhones can still open link tags.
